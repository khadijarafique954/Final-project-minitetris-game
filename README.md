## Project Overview

Mini Tetris Game is a simple Java Swing application developed using Object-Oriented Programming (OOP) concepts. The game allows the player to move a block left, right, downward, and randomly within a 10×10 grid.

## Features

* Move block to the left
* Move block to the right
* Move block downward
* Random block movement
* Game Over message
* Clear button to restart the game
* Simple graphical user interface (GUI)

## Technologies Used

* Java
* Java Swing
* Object-Oriented Programming (OOP)

## OOP Concepts Used

* Classes and Objects
* Constructors
* Methods
* Encapsulation
* Event Handling
* ActionListener Interface
* Random Class

## How to Run

1. Open the project in Eclipse or any Java IDE.
2. Compile the `MiniTetris.java` file.
3. Run the program.
4. Use the buttons to control the block.

## Output

The game displays a 10×10 grid where the block can be moved using buttons. When the block reaches the last row, the game shows a "GAME OVER" message.
